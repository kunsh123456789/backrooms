# Sound credits

All recorded sounds in `public/sounds/` are public domain. They were converted
to mono MP3s and trimmed; nothing else was changed.

| Sounds | Source | License |
| --- | --- | --- |
| Footsteps (carpet, concrete, wood), impacts (metal, wood, glass, punch, soft, bell) | Kenney, "Impact Sounds" (kenney.nl), via github.com/Boyquotes/kenney-impact-sounds-for-godot | CC0 1.0 |
| Doors, creaks, book pages, metal pots | Kenney, "RPG Audio" (kenney.nl), via github.com/Boyquotes/kenney-rpg-audio-for-godot | CC0 1.0 |
| Computer noise (static), low engine hum (Level 2 machinery) | Kenney, "Sci-Fi Sounds" (kenney.nl), via github.com/Boyquotes/kenney-sci-fi-sounds-for-godot | CC0 1.0 |
| Switch clicks | Kenney, "Interface Sounds" (kenney.nl), via github.com/Calinou/kenney-interface-sounds | CC0 1.0 |
| Hot spring water (Level 37) | "Yellowstone sound library - Beryl Spring - 001", NPS & MSU Acoustic Atlas / Peter Comley, Wikimedia Commons, via github.com/RinvalAi/brown-noise-library | Public domain |
| Gutter drips (Level 2) | "Gutter.ogg" by aldor, Wikimedia Commons, via github.com/RinvalAi/brown-noise-library | Public domain |

Everything else (the fluorescent hum, breathing, voices, alarm, party music,
reverb) is still synthesized in code at runtime.
